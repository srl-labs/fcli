# Demo lab (Codespaces)

A 3-stage Clos EVPN-VXLAN fabric for trying fcli in GitHub Codespaces.

This lab is vendored from the [Nokia Validated Designs](https://github.com/nokia/nokia-validated-designs) repository:

`validated-designs/3-stage-evpn-vxlan/3-stage-evpn-vxlan-clab-without-eda/`

The topology file was renamed from `3-stage-without-eda.clab.yaml` to `demo.clab.yaml`, and the lab name was changed to `demo`. All other files are unchanged.

## Contents

- **8 SR Linux nodes:** `spine1`, `spine2`, `leaf1`–`leaf6`
- **9 Linux servers:** `s1`–`s9`
- **Fabric:** EVPN-VXLAN with multi-homed servers
